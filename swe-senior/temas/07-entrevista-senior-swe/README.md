# Entrevista Senior Software Engineer: formato y simulacro

Tema final, para después de haber pasado por los temas 01-06 con ≥ 80% en
sus exámenes (ver `../../00-diagnostico/roadmap.md`). Simula el formato
típico de una entrevista Senior SWE en una empresa tech (Nubank incluida),
combinando varias rondas.

## Formato típico (referencia general, no garantizado para esta empresa puntual)

1. **Coding/algoritmos**: problema de complejidad media, evaluando no solo
   la solución sino comunicación del razonamiento. Para este rol, vale la
   pena poder resolverlo también en **Clojure** (no solo Python), aunque sea
   con ayuda de referencia de sintaxis.
2. **System design**: diseñar un sistema distribuido desde cero (ej. "diseñá
   un sistema de procesamiento de pagos") — usar el vocabulario y patrones
   de `../02-sistemas-distribuidos-hexagonal/` (arquitectura hexagonal,
   circuit breakers, particionamiento de Kafka, elección Datomic vs.
   DynamoDB).
3. **Behavioral/liderazgo**: preguntas tipo STAR, ver
   `../06-liderazgo-tecnico-mentoria/`.
4. **Cultural fit / values**: preguntas sobre cómo trabajás en equipo, cómo
   manejás desacuerdos, feedback.

## Cómo usar este tema

Pedime cualquiera de estos formatos:

- *"Simulá una entrevista de coding de 45 minutos, dame un problema medio"*
- *"Simulá una entrevista de system design: diseñá un sistema de pagos"*
- *"Mezclá preguntas de los temas 01 a 06 en formato entrevista, una por
  vez"* (repaso mixto final, antes de la entrevista real)
