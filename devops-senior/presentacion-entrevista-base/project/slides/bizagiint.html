Model answer: “Integration work at Bizagi had three faces. First, identity: I configured single sign-on with Microsoft Entra ID using OIDC (OpenID Connect) in production, so users sign in with their corporate account and our application trusts the tokens Entra ID issues instead of managing its own passwords. Second, external providers, such as the service that sends the platform’s emails: connecting our platform to those third parties. And third, continuous integration: every change was built and tested automatically in Azure Pipelines and Jenkins.” If they ask how OIDC works: “The app redirects the user to Entra ID; the user authenticates there, with MFA if required; Entra ID sends back an authorization code, the app exchanges it for an ID token — a signed JWT — and validates the signature, the issuer and the audience. The app never sees the password.” ES: Completa el nombre del proveedor de correos si lo recuerdas [proveedor: ___] y cómo guardaban sus credenciales. No afirmes nada que no hiciste.
