Model answer: “At Mercado Libre I co-developed a system that diagnoses support tickets with Claude. When a team opens a ticket in Zendesk, Claude reads it and gathers context two ways: RAG (Retrieval-Augmented Generation) over our runbooks and over similar tickets that were already resolved, and MCP (Model Context Protocol) servers that let it query the live state — the clusters, the deployments, the metrics. It runs inside a harness with hooks, so it can look but not change anything. The output is a diagnosis that separates certainties — facts it verified — from hypotheses — possible causes, ranked —, plus a suggested fix. It never resolves the ticket by itself: an engineer reviews the diagnosis and decides. That cut the time we spent on the first investigation of every ticket.” ES: Corrección importante frente a la versión anterior de tu presentación: NO auto-resolvía. Diagnosticaba y sugería. Si tienes una cifra real de ahorro de tiempo, dila; si no, no inventes un número.
