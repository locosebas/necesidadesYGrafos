What a diagnosis looks like

Certainties

Verified through MCP

  • 3 of 6 Pods in CrashLoopBackOff since 10:42
  • A new version was deployed at 10:40
  • Exit code 137: OOMKilled

Hypotheses

Ranked, not yet proven

  1. Memory limit too low for the new version
  2. Memory leak introduced in the release

Suggestion

For the engineer to decide

  • Roll back to the previous version
  • Compare memory usage of both versions
  • Similar ticket and runbook linked
Use this if they ask “what did the output look like?” — it’s an illustrative example, not a real ticket. “The key design decision was to make the model separate what it knows from what it suspects. Certainties are facts it verified with the MCP tools — Pods in CrashLoopBackOff, a deploy two minutes before, exit code 137. Hypotheses are ranked possible causes it hasn’t proven. And the suggestion is for the engineer, with links to the similar ticket and the runbook. Separating them reduces the risk of the engineer trusting a hallucination, because every certainty can be checked.” ES: Este ejemplo es ilustrativo (está marcado en la diapositiva).
