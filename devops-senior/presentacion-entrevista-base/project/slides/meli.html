Then I moved to Mercado Libre. We had an internal Platform as a Service that we ran ourselves. I was on the compute side: development teams deploy their applications, and we provide the compute underneath, with Kubernetes and AWS ECS (Elastic Container Service). The infrastructure lived in AWS and GCP, provisioned with Terraform — our own modules and state management. I wrote Kubernetes operators in Go and Python, handled day-to-day troubleshooting, and supported Mercado Pago, which is a regulated banking environment, so security and reliability were critical. ES: Si preguntan "¿qué es un Operator?": un Operator = CRD (Custom Resource Definition) + un controlador propio que ejecuta un reconciliation loop para un recurso de dominio.
