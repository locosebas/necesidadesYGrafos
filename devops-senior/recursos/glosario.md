# Glosario rápido

Términos que aparecen seguido en los temas de este repo y en la vacante de
Julieta. Referencia rápida, no reemplaza leer el tema completo.

| Término | Definición corta |
|---|---|
| ACA | Azure Container Apps — serverless containers sobre Kubernetes/KEDA/Dapr |
| ACR | Azure Container Registry — registro privado de imágenes de contenedor |
| OIDC | OpenID Connect — protocolo de federación de identidad, usado para que GitHub Actions se autentique en Azure sin secretos de larga duración |
| Managed Identity | Identidad gestionada por Azure para un recurso, sin credenciales que administrar manualmente |
| RBAC | Role-Based Access Control — autorización basada en roles asignados sobre un scope |
| Private Endpoint | NIC privada dentro de una VNet que conecta a un recurso PaaS, evitando exposición pública |
| NSG | Network Security Group — reglas de firewall a nivel subnet/NIC en Azure |
| RU | Request Unit — unidad de medida de throughput en Cosmos DB |
| KQL | Kusto Query Language — lenguaje de consulta usado en Log Analytics/Application Insights |
| Orchestrator function | Función en Durable Functions que coordina el flujo, debe ser determinística |
| IaC | Infrastructure as Code |
| Bicep | DSL declarativo de Microsoft para IaC en Azure, compila a ARM JSON |
| KEDA | Kubernetes Event-Driven Autoscaling — usado por ACA y AKS para escalar según eventos externos (colas, HTTP, etc.) |
